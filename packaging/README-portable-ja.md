# インストール／アンインストール（レジストリ不使用）

- `Mac`: `build-macos.sh`で作った`DMG`を開き、`install-macos.command`を実行。本体は`~/Applications/Codex Safe Resume.app`、デスクトップには本体へのシンボリックリンクを作成。`uninstall-macos.command`で配置した本体・リンクのみ削除。
- `Windows`: `build-windows.ps1`で作った`Portable ZIP`を展開し、`install-windows.ps1`を`PowerShell`から実行。本体は`%LOCALAPPDATA%\Programs\CodexSafeResume`、デスクトップに`.lnk`ショートカットを作成。`uninstall-windows.ps1`で本体・対象リンクのみ削除。
- `Windows`の`Inno Setup`インストーラーは使用しない。レジストリへのアプリ登録、サービス登録、スタートアップ登録、タスクスケジューラ登録は行わない。
- 設定はデフォルトで保持（`Codex`側のデータは絶対に削除しない）。設定まで削除したい場合だけ、`Windows`は`-RemoveUserSettings`、`Mac`は`--remove-settings`を明示して実行。
- 同名の既存配置は上書きしない。アップデート手順は実機で確認するまで自動化しない。
- シェル実行ポリシー、`OS`の警告表示、権限を回避する処理は組み込まない。
- **`Windows`の`OS`内部処理が一切レジストリを更新しないことまでは保証できない**。少なくとも本ツールのインストール／アンインストールスクリプトはレジストリ操作を行わない。
- 実験版です。再起動前提の自動接続は両`OS`で廃止しました。現在のソースには起動済みの公式アプリへ接続する共通方式を実装しています。自然な利用枠回復と両`OS`での実機受入は未完了です。旧配布物へ新ソースの実績を流用しません。対象版ごとの検証結果と残務は`Issue` #11を正本とします。

## 配置と削除の安全検査

`macOS`は配布物内の共通シェルを、`Windows`は共通`PowerShell`スクリプトを同梱して実行します。`Windows`のスクリプトは`PowerShell 7`以降の `pwsh -File` で実行してください。システム設定、レジストリ、ログイン時の自動起動は変更しません。

配置の所有記録とファイルのハッシュを保存し、削除前に一致を確認します。追加・変更ファイル、未知の設定、`symlink`、`junction`や`reparse point`、別用途の起動アイコンがある場合は、対象を保持して停止します。既存の旧版に所有記録がない場合も、自動削除しません。

本体の削除だけでは設定を消しません。設定削除は`macOS`の `--remove-settings`、`Windows`の `-RemoveUserSettings` を本人が明示した場合だけ実施します。会話データや`Codex`本体には触れません。

## ビルドと検証の境界

ビルド依存は `requirements-build.lock` の版とハッシュを使います。`macOS`の署名はアドホック署名で、公証や信頼済み発行者を示すものではありません。`Windows`の署名は未実施です。

隔離フォルダーでの所有記録・リンク拒否の検証と、実機でのインストール・トレイ常駐・アンインストールは別の確認です。両`OS`の実機受入まで安定版ではありません。未検証で別の削除経路を持つ`Inno Setup`用定義は除去し、`portable`配布に限定しています。

## `Desktop`接続用プログラム

`Windows`の配置スクリプトは`Safe Resume`本体とその画面を開くアイコンだけを配置します。通常起動済みの`Codex`への接続は、公式キュー受付と実行状態の照合を使います。再起動や専用起動を要求する方式は廃止しました。公式`Codex`のアイコンと起動方法は変更しません。旧版で作成した接続用アイコンは、削除スクリプトが所有者・実体・引数を検証できる場合だけ片付けます。

配布物内の旧中継コードは開発用の隔離検査に使います。`Mac`でも接続のために公式`Desktop`を開き直す手順は提供しません。利用枠・送信・到達照合は共通方式とし、実プロセス・署名・通信相手の確認は`OS`固有です。現在の提供範囲と検証の境界は [接続設定](../docs/接続設定.md) を参照してください。

## `Windows`実機受入候補の取得

`GitHub Actions`の`「全OSの回帰検査と配布ビルド」`で、対象`main`の必須チェックがすべて成功した実行を開きます。`Artifacts`の `CodexSafeResume-Windows-<対象SHA>` を取得して展開すると、`Portable ZIP`と `windows-acceptance.json` が入っています。保持期間は14日です。`PR`の実行からは候補を保存しません。

`JSON`の `source_sha` が検証対象の`main`と一致し、`Portable ZIP`の`SHA256`が `sha256` と一致することを確認してから`ZIP`を展開します。`PowerShell 7`では `Get-FileHash -LiteralPath .\CodexSafeResume-Windows-Portable.zip -Algorithm SHA256` で照合できます。照合が取れない候補や期限切れ候補は使いません。

これは未署名の実機受入候補です。アップロード成功や`CI`成功は、`Windows`実機の起動・接続・常駐・再開成功を意味しません。`OS`の警告・実行ポリシー・権限を回避せず、診断・配置・自動再開`OFF`での画面確認から実施します。安定版リリースと受入完了は`Issue` #11で別途管理します。
